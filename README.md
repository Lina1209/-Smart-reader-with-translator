# Read & Translate — умная читалка с переводчиком

Небольшая браузерная читалка для комфортного чтения электронных книг. Откройте файл, выделите незнакомое слово или фрагмент и получите перевод прямо во время чтения.

## Возможности

- **Форматы:** EPUB, FB2, TXT, PDF с текстовым слоем и DOCX. PDF-сканы без текстового слоя требуют отдельного OCR и пока не распознаются.
- **Перевод выделенного текста:** выбор исходного и целевого языка из расширенного списка (142 языка из каталога MyMemory); автоматическое определение поддерживает ряд распространённых письменностей. Для латинских языков исходный язык нужно выбрать вручную, поскольку надёжно различить их только по алфавиту нельзя.
- **Озвучивание книг:** системные голоса браузера/устройства, выбор доступного голоса, настройка скорости, пауза и остановка. Для EPUB озвучивается открытая глава, для FB2, TXT, PDF и DOCX — извлечённый текст целиком.
- **Отдельный модуль TTS:** `tts.js` находится в корне проекта и подключается к читалке.
- **Настройка чтения:** изменение размера шрифта, светлая, тёплая (сепия) и ночная темы.
- **EPUB-навигация:** перелистывание кнопками.
- **Полноэкранный режим:** удобнее читать на небольшом экране.
- **Адаптивный интерфейс:** поддержка смартфонов, планшетов и компьютеров.
- **Демо:** пробный английский текст для знакомства с переводом.

## Как пользоваться

1. Откройте сайт в современном браузере.
2. Нажмите **«Открыть книгу»** или перетащите файл в область загрузки.
3. Выделите слово, предложение или небольшой фрагмент текста.
4. Прочитайте перевод во всплывающей карточке. При необходимости скопируйте его или прослушайте оригинал.
5. В панели **«Чтение вслух»** выберите доступный голос, настройте скорость и нажмите **«Читать»**. Кнопки паузы и остановки управляют воспроизведением.
6. Настройте размер шрифта и тему под себя.

## Важно знать

- Для перевода требуется подключение к интернету. Перевод выполняется через публичный сервис MyMemory; доступность и ограничения зависят от сервиса.
- Для EPUB используется библиотека epub.js, загружаемая с jsDelivr. Для первого открытия EPUB требуется интернет.
- Встроенный модуль `tts.js` использует стандартный Web Speech API. Он не устанавливает отдельный системный движок: список голосов предоставляет браузер и ОС. На Android при необходимости включите Google Speech Services (или другой TTS-движок) и загрузите нужные языковые голоса в настройках устройства.
- Книги открываются локально в браузере и не отправляются на сервер приложения. Выделенный текст передаётся внешнему сервису только при запросе перевода.
- MyMemory принимает до 500 байт текста на один запрос; длинный текст автоматически делится на небольшие фрагменты. Бесплатное анонимное использование ограничено 5 000 символами в сутки, поэтому при большом объёме перевод может временно остановиться.
- PDF импортируется только при наличии текстового слоя. OCR для изображений и сканированных страниц пока не реализован.
- Перевод доступен только для языковых пар, которые фактически обслуживает MyMemory; наличие языка в списке не гарантирует наличие каждой возможной пары.

## Технологии

HTML, CSS, JavaScript, [epub.js](https://github.com/futurepress/epub.js), PDF.js, Mammoth, MyMemory Translation API и Web Speech API.

## Запуск

Это статическое веб-приложение. Откройте `index.html` через локальный веб-сервер или разместите репозиторий на GitHub Pages.
