# Read & Translate — читай, понимай, открывай новое

**Одна страница — три полезных инструмента: читалка, переводчик и транслитератор.**

Бывает, встречаешь в книге незнакомое слово — и приходится закрывать чтение, искать перевод, переключаться между сайтами. С Read & Translate можно остаться в тексте: открыть книгу, выделить фрагмент и посмотреть перевод. А если нужно записать русские слова латиницей — рядом есть отдельный транслитератор.

Это небольшой браузерный помощник для тех, кто любит читать, изучать языки, работать с текстами и не хочет терять время на лишние переходы.

> **Попробуйте три режима приложения:**
> - 📖 **Читалка** — открывайте электронные книги и документы, настраивайте размер шрифта и тему, читайте в полноэкранном режиме.
> - 🌐 **Переводчик** — вводите или вставляйте текст, выбирайте исходный и целевой языки и получайте перевод.
> - 🔤 **Транслитератор** — преобразуйте русский текст в латинскую запись. Это удобно для имён, заметок, адресов и подготовки текста.

## Возможности

- **Импорт документов:** EPUB, FB2, TXT, PDF с текстовым слоем, Word DOCX, Excel XLSX/XLS/XLSM, ODT, RTF, HTML/HTM, Markdown, CSV, XML, JSON, LOG, SRT и VTT. Для текстовых файлов предусмотрено чтение UTF-8 и fallback для Windows-1251; RTF и ODT разбираются отдельно. Книги Excel открываются с извлечением данных всех листов и сохранением порядка строк и столбцов в текстовом представлении.
- **Перевод выделенного текста в читалке:** выбор исходного и целевого языка из расширенного списка (142 языка из каталога MyMemory); можно выбрать автоматическое определение исходного языка, в том числе для языков с латинским алфавитом. Для коротких фраз, имён и отдельных слов рекомендуется при необходимости указать язык вручную.
- **Отдельный переводчик:** ввод или вставка текста, выбор языковой пары, получение и копирование результата.
- **Транслитератор:** преобразование русского текста в латинскую запись; можно ввести текст вручную или загрузить документ.
- **Озвучивание книг:** системные голоса браузера/устройства, выбор доступного голоса, настройка скорости, пауза и остановка. Для EPUB озвучивается открытая глава, для текстовых форматов, включая FB2, TXT, PDF, DOCX, ODT и RTF — извлечённый текст.
- **Отдельный модуль TTS:** `tts.js` находится в корне проекта и подключается к читалке.
- **Настройка чтения:** изменение размера шрифта, светлая, тёплая (сепия) и ночная темы.
- **EPUB-навигация:** перелистывание кнопками.
- **Полноэкранный режим:** удобнее читать на небольшом экране.
- **Экспорт оригинала и результата:** TXT, EPUB, FB2, Markdown, RTF, HTML, DOCX и ODT. PDF формируется через системное окно печати браузера — выберите «Сохранить как PDF».
- **Адаптивный интерфейс:** поддержка смартфонов, планшетов и компьютеров.
- **Демо:** пробный английский текст для знакомства с переводом.

## Как пользоваться

1. Откройте приложение в современном браузере.
2. Выберите нужный режим: **«Читалка»**, **«Переводчик»** или **«Транслитератор»**.
3. В читалке нажмите **«Открыть книгу»** или загрузите файл в выбранном текстовом инструменте.
4. Для перевода выделите слово или фрагмент в книге либо вставьте текст в режим «Переводчик».
5. Для транслитерации вставьте русский текст в левое поле режима **«Транслитератор»** — латинская запись появится автоматически.
6. Скопируйте результат или сохраните его в подходящем формате.
7. В читалке при желании настройте шрифт, тему и озвучивание.

## Важно знать

- Для перевода требуется подключение к интернету. По умолчанию используется MyMemory; дополнительно можно подключить собственный сервер LibreTranslate. Доступность языковых пар, скорость и квоты зависят от выбранного сервиса и его конфигурации.
- Для EPUB используется библиотека epub.js, загружаемая с jsDelivr. Для первого открытия EPUB требуется интернет.
- Встроенный модуль `tts.js` использует стандартный Web Speech API. Он не устанавливает отдельный системный движок: список голосов предоставляет браузер и ОС. На Android при необходимости включите Google Speech Services (или другой TTS-движок) и загрузите нужные языковые голоса в настройках устройства.
- Книги открываются локально в браузере и не отправляются на сервер приложения. Выделенный текст передаётся внешнему сервису только при запросе перевода.
- MyMemory принимает до 500 байт текста на один запрос; приложение использует запас до 450 UTF-8 байт. Фрагменты стараются завершаться на границе абзаца или предложения, не теряя пробелы и символы. Для LibreTranslate применяется отдельный консервативный размер фрагмента 4 000 UTF-8 байт; фактический предел задаёт владелец сервера. Анонимный MyMemory ограничивает использование 5 000 символами в сутки.
- PDF с текстовым слоем извлекается напрямую с учётом признаков конца строки PDF.js; страницы без текстового слоя обрабатываются OCR. Для OCR проверяются границы распознанных строк; при низкой уверенности запускается дополнительное распознавание с увеличением изображения и повышением контраста, а затем при необходимости проверяются повороты страницы; для китайского и японского перевода перенос выполняется по графемам. Это помогает не склеивать соседние строки при чтении обычных PDF, хотя сложные многоколоночные макеты всё ещё требуют проверки. Для перевода PDF с сохранением визуальной структуры доступна реконструкция до 80 страниц: она растрирует страницы, поэтому выделение/поиск текста и векторные элементы теряются. Изображения PNG/JPG/WEBP также проходят OCR и получают заменённые надписи; GIF обрабатывается по первому кадру как статичное изображение, а результат экспортируется в PNG без анимации.
- Для устойчивости браузерная обработка ограничена файлами до 100 МБ; Excel — до 50 МБ, PDF — до 2 000 страниц. Большие файлы лучше разбить заранее.
- Запрос перевода имеет тайм-аут 20 секунд. Текст делится на UTF-8 фрагменты с сохранением пробелов; при сбое можно скопировать уже переведённую часть из сообщения.
- При временных сетевых сбоях и ответах сервера 408/425/5xx приложение автоматически делает до двух повторных попыток с увеличивающейся паузой. Ошибки дневной квоты и некорректной языковой пары автоматически не повторяются.
- В поле **«Глоссарий перевода»** можно указать пары `исходный термин = точный перевод`, по одной на строку. Приложение временно защищает найденные термины от изменения движком и восстанавливает заданный вариант после перевода. Глоссарий действует на перевод в рамках открытой страницы; не вводите туда конфиденциальные данные.
- Лимит MyMemory (5 000 символов в сутки) — внешний лимит сервиса; приложение не может гарантировать точный остаток квоты пользователя.
- Старый бинарный Word `.doc`, Kindle `.mobi`/`.azw`/`.azw3`, комиксы CBZ/CBR и архивы ZIP как самостоятельные книги пока не поддерживаются. Их нужно предварительно преобразовать в EPUB, PDF, DOCX, ODT, RTF или TXT. Excel `.xlsx`, `.xls` и `.xlsm` импортируются как текстовые таблицы: извлекаются отображаемые значения ячеек всех листов; формулы, оформление, диаграммы и изображения не переносятся. Макросы XLSM не запускаются и не исполняются.
- PDF при экспорте открывает диалог печати браузера. На телефоне выберите системное действие «Сохранить как PDF»; прямое создание PDF-файла без диалога не заявляется.
- Кнопки обычного экспорта в DOCX/ODT создают текстовые документы из результата. Для форматов с поддержкой исходного контейнера используйте отдельную кнопку **«Скачать перевод с сохранением формата»**; сохранение структуры не гарантирует пиксельное совпадение, а длинный перевод может менять переносы и пагинацию.
- При переводе DOCX текст заменяется внутри исходных XML-абзацев и текстовых фрагментов, а не собирается заново из обычного текста; таблицы, изображения и стили остаются в исходном контейнере. При нескольких форматированных фрагментах пробелы, табуляции и переносы строк в переводе сохраняются при распределении текста по фрагментам. EPUB дополнительно обрабатывает списки, подписи и заголовки до шестого уровня; PPTX обрабатывает слайды в числовом порядке. Длинный перевод всё равно может менять переносы строк и размеры блоков.
- Перевод доступен только для языковых пар, которые фактически обслуживает MyMemory; наличие языка в списке не гарантирует наличие каждой возможной пары.

## Перевод файлов с сохранением исходного формата

В диагностической ветке добавлен отдельный режим перевода загруженного файла: после перевода доступна кнопка **«Скачать перевод с сохранением формата»**. Он сохраняет оригинальный контейнер/структуру вместо создания нового документа из простого текста.

Поддерживаемые форматы этой функции:
- **DOCX** — сохраняется архив документа, страницы/параграфы, таблицы, изображения, стили абзацев, headers/footers, footnotes; текст каждого абзаца переводится внутри существующей структуры.
- **EPUB** — сохраняются файлы книги, CSS, обложка, изображения, навигация и метаданные; переводятся параграфы и основные заголовки.
- **ODT** — сохраняется контейнер, стили и ресурсы; переводятся текстовые параграфы и заголовки.
- **FB2 / HTML** — сохраняется исходная XML/HTML структура, ссылки и изображения; переводимые текстовые блоки заменяются на месте.
- **PPTX** — сохраняются слайды, макеты, изображения и shapes; переводится текст внутри слайдов.
- **XLSX / XLSM** — сохраняются листы, формулы, стили и workbook; переводятся строковые значения, включая shared/inline strings.
- **TXT, MD, CSV, JSON, LOG, SRT, VTT** — сохраняется расширение и текстовый формат; переводы выполняются по содержимому.

**Ограничения:** перевод может быть длиннее оригинала и нарушить исходную пагинацию/переносы или переполнить ячейку/текстовый блок. В DOCX и некоторых XML-форматах перевод абзаца помещается в первый текстовый run, поэтому смешанное inline-форматирование внутри одного абзаца может частично измениться. PDF, RTF, старый XLS, сканированные PDF и форматы с DRM пока не собираются в перевод с гарантированным сохранением дизайна. Для них доступен перевод извлечённого текста (если парсер поддерживает файл). Это не обещание пиксельного совпадения и требует тестирования реальными файлами.


## Движки перевода

В интерфейсе переводчика можно выбрать один из движков:

- **MyMemory** — работает без настройки и остаётся вариантом по умолчанию. У сервиса есть ограничения по частоте и объёму запросов.
- **Свой LibreTranslate** — подключение к самостоятельно размещённому серверу LibreTranslate. Установите движок отдельно, загрузите только необходимые языковые модели и укажите в поле адрес сервера с HTTPS. Самостоятельно размещённый LibreTranslate использует Argos Translate как локальный движок и может работать без внешнего API. Сервер должен разрешать CORS-запросы с домена приложения; набор языков зависит от установленных моделей.

Пример запуска собственного сервера (на сервере или локальном компьютере):

\`\`\`bash
pip install libretranslate
libretranslate --load-only en,ru,kk
\`\`\`

Список языков в команде — пример, а не гарантия наличия готовых моделей для каждой пары. Проверьте установленные пары через API сервера перед использованием. Для локального компьютера веб-приложение, открытое по HTTPS, не сможет обращаться к HTTP-адресу из-за ограничений браузера; используйте HTTPS endpoint или локальную сборку с корректно настроенным доступом.

**Важно по безопасности:** в приложении пока не хранятся ключи DeepL/Azure и не выполняется прямой вызов этих коммерческих API из браузера. Для них нужен серверный прокси (например, Cloudflare Worker) с ключами в секретах окружения, лимитами запросов и защитой от злоупотребления. Не вставляйте секретные API-ключи в HTML или публичный JavaScript.

**Ориентиры по тарифам на 26 ноября 2026 года:** Azure Translator указывает F0 с 2 млн символов в месяц бесплатно; DeepL API Free — до 500 тыс. символов в месяц, но план больше нельзя оформить новым пользователям; Railway Hobby — минимум $5/мес с включённым кредитом на ресурсы, а не фиксированные $5–15 за любой объём. Фактическая стоимость размещения зависит от CPU, RAM, хранилища и сетевого трафика. Перед подключением сверяйте актуальные условия у провайдеров.
