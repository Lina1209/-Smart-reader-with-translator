# Read & Translate — читай, понимай, открывай новое

**Одна страница — три полезных инструмента: читалка, переводчик и транслитератор.**

Бывает, встречаешь в книге незнакомое слово — и приходится закрывать чтение, искать перевод, переключаться между сайтами. С Read & Translate можно остаться в тексте: открыть книгу, выделить фрагмент и посмотреть перевод. А если нужно записать русские слова латиницей — рядом есть отдельный транслитератор.

Это небольшой браузерный помощник для тех, кто любит читать, изучать языки, работать с текстами и не хочет терять время на лишние переходы.

> **Попробуйте три режима приложения:**
> - 📖 **Читалка** — открывайте электронные книги и документы, настраивайте размер шрифта и тему, читайте в полноэкранном режиме.
> - 🌐 **Переводчик** — вводите или вставляйте текст, выбирайте исходный и целевой языки и получайте перевод.
> - 🔤 **Транслитератор** — преобразуйте русский текст в латинскую запись. Это удобно для имён, заметок, адресов и подготовки текста.

## Возможности

- **Импорт документов:** EPUB, FB2, TXT, PDF с текстовым слоем, Word DOCX, Excel XLSX/XLS/XLSM, ODT, RTF, HTML/HTM, Markdown, CSV, XML, JSON, LOG, SRT и VTT. Для текстовых файлов предусмотрено чтение UTF-8 и fallback для Windows-1251; RTF и ODT разбираются отдельно. Книги Excel открываются с извлечением данных всех листов и сохранением порядка строк и столбцов в текстовом представлении.
- **Перевод выделенного текста в читалке:** выбор исходного и целевого языка из расширенного списка (142 языка из каталога MyMemory); можно выбрать автоматическое определение исходного языка, в том числе для языков с латинским алфавитом. Для коротких фраз, имён и отдельных слов рекомендуется при необходимости указать язык вручную.
- **Отдельный переводчик:** ввод или вставка текста, выбор языковой пары, получение и копирование результата.
- **Транслитератор:** преобразование русского текста в латинскую запись; можно ввести текст вручную или загрузить документ.
- **Озвучивание книг:** системные голоса браузера/устройства, выбор доступного голоса, настройка скорости, пауза и остановка. Для EPUB озвучивается открытая глава, для текстовых форматов, включая FB2, TXT, PDF, DOCX, ODT и RTF — извлечённый текст.
- **Отдельный модуль TTS:** `tts.js` находится в корне проекта и подключается к читалке.
- **Настройка чтения:** изменение размера шрифта, светлая, тёплая (сепия) и ночная темы.
- **EPUB-навигация:** перелистывание кнопками.
- **Полноэкранный режим:** удобнее читать на небольшом экране.
- **Экспорт оригинала и результата:** TXT, EPUB, FB2, Markdown, RTF, HTML, DOCX и ODT. PDF формируется через системное окно печати браузера — выберите «Сохранить как PDF».
- **Адаптивный интерфейс:** поддержка смартфонов, планшетов и компьютеров.
- **Демо:** пробный английский текст для знакомства с переводом.

## Как пользоваться

1. Откройте приложение в современном браузере.
2. Выберите нужный режим: **«Читалка»**, **«Переводчик»** или **«Транслитератор»**.
3. В читалке нажмите **«Открыть книгу»** или загрузите файл в выбранном текстовом инструменте.
4. Для перевода выделите слово или фрагмент в книге либо вставьте текст в режим «Переводчик».
5. Для транслитерации вставьте русский текст в левое поле режима **«Транслитератор»** — латинская запись появится автоматически.
6. Скопируйте результат или сохраните его в подходящем формате.
7. В читалке при желании настройте шрифт, тему и озвучивание.

## Важно знать

- Для перевода требуется подключение к интернету. Перевод выполняется через публичный сервис MyMemory; доступность и ограничения зависят от сервиса.
- Для EPUB используется библиотека epub.js, загружаемая с jsDelivr. Для первого открытия EPUB требуется интернет.
- Встроенный модуль `tts.js` использует стандартный Web Speech API. Он не устанавливает отдельный системный движок: список голосов предоставляет браузер и ОС. На Android при необходимости включите Google Speech Services (или другой TTS-движок) и загрузите нужные языковые голоса в настройках устройства.
- Книги открываются локально в браузере и не отправляются на сервер приложения. Выделенный текст передаётся внешнему сервису только при запросе перевода.
- MyMemory принимает до 500 байт текста на один запрос; длинный текст автоматически делится на небольшие фрагменты. Бесплатное анонимное использование ограничено 5 000 символами в сутки, поэтому при большом объёме перевод может временно остановиться.
- PDF импортируется только при наличии текстового слоя. OCR для изображений и сканированных страниц пока не реализован.
- Старый бинарный Word `.doc`, Kindle `.mobi`/`.azw`/`.azw3`, комиксы CBZ/CBR и архивы ZIP как самостоятельные книги пока не поддерживаются. Их нужно предварительно преобразовать в EPUB, PDF, DOCX, ODT, RTF или TXT. Excel `.xlsx`, `.xls` и `.xlsm` импортируются как текстовые таблицы: извлекаются отображаемые значения ячеек всех листов; формулы, оформление, диаграммы и изображения не переносятся. Макросы XLSM не запускаются и не исполняются.
- PDF при экспорте открывает диалог печати браузера. На телефоне выберите системное действие «Сохранить как PDF»; прямое создание PDF-файла без диалога не заявляется.
- DOCX и ODT экспортируются как текстовые документы с абзацами; сложная исходная вёрстка, изображения, таблицы и стили не переносятся.
- Перевод доступен только для языковых пар, которые фактически обслуживает MyMemory; наличие языка в списке не гарантирует наличие каждой возможной пары.

## Технологии

HTML, CSS, JavaScript, [epub.js](https://github.com/futurepress/epub.js), PDF.js, Mammoth, JSZip, MyMemory Translation API и Web Speech API.

## Запуск

Это статическое веб-приложение. Откройте `index.html` через локальный веб-сервер или разместите репозиторий на GitHub Pages.
