# Подключение дополнительных переводчиков

Сайт остаётся статическим на GitHub Pages. Этот Worker служит защищённым шлюзом: ключи провайдеров хранятся в Cloudflare Secrets, а не в репозитории и не в браузере.

## Поддерживаемые движки

- Google Cloud Translation Basic (v2)
- Microsoft Azure Translator
- DeepL API
- LibreTranslate (собственный или управляемый сервер)
- MyMemory — остаётся клиентским резервным сервисом в приложении

Worker пробует выбранный движок первым, затем остальные настроенные. Если Worker не настроен или все дополнительные движки недоступны, приложение автоматически использует MyMemory. Перевод выполняется небольшими фрагментами; уже готовые фрагменты не теряются.

## Развёртывание Cloudflare Worker

1. В Cloudflare откройте Workers & Pages → Create → Worker.
2. Создайте Worker и замените содержимое его редактора файлом `worker.js` из этой папки.
3. Откройте Settings → Variables and Secrets и добавьте секреты (только те провайдеры, которыми будете пользоваться):
   - `GOOGLE_TRANSLATE_API_KEY` — ключ Google Cloud Translation Basic API (v2).
   - `AZURE_TRANSLATOR_KEY` — ключ ресурса Azure Translator.
   - `AZURE_TRANSLATOR_ENDPOINT` — endpoint ресурса Azure, например `https://api.cognitive.microsofttranslator.com`.
   - `AZURE_TRANSLATOR_REGION` — регион, если он требуется типом вашего ресурса.
   - `DEEPL_API_KEY` — ключ DeepL API.
   - `LIBRETRANSLATE_URL` — адрес сервера LibreTranslate (если используете).
   - `LIBRETRANSLATE_API_KEY` — ключ LibreTranslate, если он требуется сервером.
4. Добавьте обычную переменную `ALLOWED_ORIGIN` со значением `https://lina1209.github.io`.
5. Нажмите Deploy и скопируйте URL Worker.
6. В Read & Translate откройте «Дополнительные переводчики · настройки подключения», вставьте URL Worker и сохраните.

**Важно:** не публикуйте API-ключи в чате, GitHub, скриншотах или поле адреса Worker. В Cloudflare выбирайте тип Secret для ключей. Для публичного использования дополнительно настройте Cloudflare Rate Limiting/лимиты запросов и бюджетные ограничения у провайдеров: проверка Origin сама по себе не является полноценной защитой от злоупотребления.

## Подключение аккаунтов

- Google: создайте проект Google Cloud, включите Cloud Translation API и настройте биллинг и API key для Basic v2.
- Azure: создайте ресурс Translator и возьмите Key и Endpoint со страницы Keys and Endpoint.
- DeepL: создайте API-ключ в аккаунте DeepL API.
- LibreTranslate: укажите URL собственного сервера или выбранного управляемого хостинга.

Не нужно подключать все платформы сразу. Начните с одной или двух; остальные Worker будет пропускать, пока их секреты не добавлены.

## Проверка

После настройки:
1. В приложении выберите движок или «Автоматически».
2. Переведите короткую фразу.
3. Статус должен показать название фактически использованного движка.
4. Временно отключите/удалите его ключ в Cloudflare и повторите тест: следующий настроенный движок должен принять запрос, а при недоступности всех дополнительных сервисов — MyMemory.

Worker ограничивает один запрос 500 байтами, чтобы соответствовать текущему разбиению текста в приложении.
